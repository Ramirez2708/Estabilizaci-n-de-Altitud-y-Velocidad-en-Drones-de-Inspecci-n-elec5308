01 · Contexto industrial

Arquitectura del sistema de control

Un dron de inspección debe mantener una altura de referencia mientras realiza tareas de observación. Para este modelo se estudia únicamente el movimiento vertical; la dinámica lateral y la orientación quedan fuera del alcance.

Planta

Dinámica vertical del dron: masa, gravedad y resistencia aerodinámica.

Sensor

Altímetro/barómetro o sensor de distancia que estima la altura y la devuelve al controlador.

Controlador

PID que calcula una corrección de empuje a partir del error entre altura deseada y medida.

Actuador

Conjunto de motores y hélices que modifica el empuje total.

Perturbaciones

Corrientes de aire, cambios de carga y variaciones del empuje disponible.

02 · Modelado matemático y linealización

De las leyes físicas al modelo

Se define el eje vertical positivo hacia arriba. La fuerza de arrastre siempre se opone al movimiento, por lo que se representa con v|v|.

ΣF = m z¨ = T − mg − c ż|ż| + d(t)
m z¨ = T − mg − c ż|ż| + d(t)

En vuelo estacionario: v₀ = 0, z¨₀ = 0 y T₀ = mg. Se definen las variables de desviación δz = z − z₀ y δT = T − T₀.

δz¨ = (1/m)δT + (1/m)δd

El arrastre cuadrático no aparece en el modelo lineal de primer orden alrededor de v₀ = 0 porque su derivada respecto a la velocidad en ese punto es cero.

G(s) = ΔZ(s)/ΔT(s) = 1/(m s²)

Representación en espacio de estados

A = [[0, 1], [0, 0]]   B = [[0], [1/m]]
C = [1, 0]   D = [0]

El controlador actúa sobre la desviación de empuje: T(t) = mg + u(t), con u(t) = Kp e(t) + Ki∫e(t)dt − Kd ż(t).

05 · Estabilidad y conclusiones

Análisis de estabilidad

Para el modelo linealizado con PID, el polinomio característico es:

m s³ + Kd s² + Kp s + Ki = 0

Con m, Kp, Ki y Kd positivos, las condiciones de Routh-Hurwitz para este polinomio son:

Kd·Kp > m·Ki

El valor final ante una referencia escalón es igual a la referencia, siempre que el lazo lineal sea estable y no haya saturación sostenida.

Realimentación invertida

Con realimentación positiva, el denominador pasa a ser m s³ − Kd s² − Kp s − Ki. Para los valores nominales, existe al menos un polo con parte real positiva, lo que indica inestabilidad del modelo lineal.

Conclusiones

  • La segunda ley de Newton permite obtener el modelo vertical del dron.
  • La resistencia cuadrática hace que el modelo físico sea no lineal.
  • La linealización alrededor del vuelo estacionario produce una planta de doble integrador.
  • El PID regula la altura mediante la corrección del empuje respecto al equilibrio.
  • La estabilidad depende de las ganancias y de la realimentación negativa correctamente conectada.
